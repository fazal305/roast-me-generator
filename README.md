# Roast Me Generator 🔥

A fun dark-mode coding roast generator built with HTML, CSS, and vanilla JavaScript.

Users type something about their coding life, like their favorite language, tool, or experience level, and the app generates a random playful roast based on their input.

## Features

- Dark fiery responsive UI
- Random coding roasts
- Keyword-based roast categories
- Roast again button
- Copy roast button
- Sound effect using Web Audio API
- Mobile vibration effect using Vibration API
- Empty input shake animation
- Category detection label
- Built with plain HTML, CSS, and JavaScript
